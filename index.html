Selected projects

FRIDAY

Embedded AI assistant · 2025

FRIDAY is a personal assistant implemented on constrained hardware, combining voice input, local memory, and response selection logic within the limits of embedded systems.

The project required designing decision flow, managing system state, and balancing latency, storage, and responsiveness while integrating software with a custom designed and 3D printed physical enclosure.

Metriqa

Personal health analytics application

Metriqa is a health analytics application designed to work exclusively with user provided data, focusing on long term trends rather than isolated daily values.

The system aggregates longitudinal data, computes changes over time, and presents meaningful summaries, including support for GLP 1 medication tracking, while maintaining data consistency and privacy.

Live Sky

Interactive web visualization

Live Sky is an interactive space visualization that maps user input to motion and depth in a real time rendered star field.

The project involves coordinate transformations, animation loops, controlled randomness, and performance aware rendering to maintain smooth interaction across devices.
